# GS Status Bar for Mac

## Support

GS Status Bar shows remaining Codex and Claude Code usage in the Mac menu bar. Open the menu and choose **Try Sample Data** to see how it works.

- **Codex** — Choose **Connect Codex** and confirm your sessions folder. GS Status Bar remembers the read-only permission and updates usage automatically.
- **Claude Code** — Choose **Copy Command**, run it in Terminal, then click **Paste** in GS Status Bar. You can also import an existing usage report from the Claude report menu.

[Contact the developer or report a problem](https://github.com/shnguo/gs-status-bar/issues/new). Include your macOS version and the steps to reproduce the issue. Keep session logs, usage reports, and credentials private.

## Privacy policy

GS Status Bar processes usage data on your Mac. It reads files in the Codex sessions folder you choose and extracts rate-limit fields. It also extracts usage limits from Claude Code reports you paste or import. The app saves your settings, the Codex folder permission, and the parsed Claude usage summary on your Mac. The original report stays in its existing location and usage data stays on your device.

Use **Disconnect** to remove the saved Codex folder permission. Choose **Clear Report** in the Claude report options to remove the saved Claude usage summary.

For privacy questions, [contact the developer](https://github.com/shnguo/gs-status-bar/issues/new).
